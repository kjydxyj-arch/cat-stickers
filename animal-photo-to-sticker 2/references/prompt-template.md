# 主 Prompt 模板

将以下内容填入 image_edit 的 prompt 参数，保留参考图片URL为用户上传的动物照片。

## 主 Prompt（中文）

请基于上传的动物照片，生成一张完整的透明底贴纸图案。严格保留动物原本的品种、脸部五官、眼睛、鼻子、嘴巴、耳朵结构、毛色花纹、身体比例、姿态、动作方向、爪子和尾巴特征，不要变成另一只动物，不要改变主体姿势，不要拉伸变形。精细抠出动物主体，去除原背景、桌面、地面、墙面和无关杂物，仅补全尾巴尖、耳尖、爪尖等小范围截断细节，不进行大面积身体补画，补全毛发边缘、轮廓断裂处和接触阴影，让主体边缘干净自然。根据动物当前姿势选择创意支撑物，可以是食物、玩具或日常物品，大小比例合理即可，例如甜甜圈、汉堡、蛋糕、冰淇淋、薯条、热狗、玩具、软垫、猫窝、纸箱等，使动作看起来有落点、有互动、有故事感。装饰元素要少量，围绕主体分布，不得遮挡眼睛、鼻子、嘴巴、爪子和关键花纹。所有支撑物和装饰元素必须是完整物体，不得被贴纸边缘截断，不得出现动物身体悬浮、消失在空气里或被硬遮断口的残疾感。风格为混合风：动物本体保留写实照片质感，道具为卡通可爱风格。整体为可爱创意贴纸风格，透明背景，外圈加均匀圆润白边，外圈白边统一到4–5px，轻微柔和投影，统一光线、色温，300 DPI印刷分辨率，构图紧凑完整，适合印刷贴纸。

## 负面 Prompt

修改动物脸，改变动物姿态，变形，残缺，半截物体，物体被裁切，悬浮动物，身体凭空消失，残疾感，扭曲五官，改动毛发花纹，拉伸，多余杂物，杂乱背景

## 工具参数建议
- model_version: seedream_4.5
- height/width: 根据原图比例调整，保持原图宽高比
- image_reference_url_list: [用户上传的动物照片URL]
