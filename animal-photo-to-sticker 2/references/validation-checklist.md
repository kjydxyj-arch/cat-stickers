# 校验清单

生成贴纸后，逐项检查以下8条，全部通过才能输出给用户：

## 校验项

1. **动物样貌没变**
   - 脸、五官、花纹、姿态和原图一致
   - 没有变成另一只动物
   - 没有拉伸变形

2. **支撑道具完整无截断**
   - 整个道具都在贴纸轮廓内
   - 没有半截物体被贴纸边缘切掉

3. **没有悬浮半截身体**
   - 动物有明确的落点和接触阴影
   - 没有身体凭空消失在空气里的感觉

4. **道具和姿势逻辑自洽**
   - 道具不是硬塞的
   - 动物和道具之间有合理的物理关系（趴着/坐着/躲着/抱着）

5. **遮挡自然**
   - 不是"贴一块布盖住断面"
   - 被遮挡部分看起来本来就应该被挡住

6. **白边闭合均匀**
   - 4~5px 宽度
   - 圆润，没有毛刺
   - 完整闭合轮廓

7. **五官无遮挡**
   - 眼睛、鼻子、嘴巴都清晰可见
   - 关键花纹没有被装饰元素挡住

8. **混合风统一**
   - 动物本体保持写实照片质感
   - 道具是卡通可爱风格
   - 两者融合自然，不突兀

## 不通过处理
- 任何一条不通过 → 重新生成或调整 Prompt
- 动物本体改动过大 → 降低重绘强度，强化"保留原图动物"的指令
- 道具被截断 → 强调"支撑物完整全部入画"
- 残疾感 → 重新设计遮挡关系，确保身体有合理承托
