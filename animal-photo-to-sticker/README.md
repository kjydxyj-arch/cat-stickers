# Animal Photo to Sticker 🐱➡️✨

动物实拍照片转印刷透明贴纸的通用 Skill。严格保留原图动物本体，添加创意支撑道具，输出适合印刷的可爱贴纸。

## 特性

- 🐾 **严格保留动物本体**：不改变脸、五官、花纹、姿势
- 🎨 **创意支撑道具**：甜甜圈、吐司、汉堡、玩具等，大小合理即可
- ✨ **混合风格**：动物写实 + 道具卡通
- 🖨️ **印刷级输出**：4~5px 白边、透明背景、300 DPI
- ✅ **完整校验清单**：避免半截身体、悬浮、道具截断等问题

## 安装

### 方式一：本地安装（自动触发）
1. 下载本仓库
2. 把 `animal-photo-to-sticker` 文件夹放到你的 `.user_skills/` 目录下
3. 新开对话，上传动物照片 + 说"生成贴纸"，自动生效

### 方式二：远程引用（无需安装）
在对话里直接说：
```
读取 https://github.com/你的用户名/你的仓库/blob/main/animal-photo-to-sticker/SKILL.md，按里面的规则处理这张动物照片
```
然后上传照片即可。

## 使用示例

> 上传一张猫照片 + 说"帮我生成动物贴纸"

输出：透明底 PNG 贴纸，带 4~5px 白边，适合印刷。

## 核心规则

### 动物本体锁定
- 严格保留品种、五官、毛色花纹、身体比例、姿态
- 仅补尾巴尖/耳尖/爪尖小细节，不大面积补身体

### 支撑道具
- 创意优先，大小合理即可，不强制大尺寸
- 道具必须完整入画，不能被贴纸边缘截断
- 动物有明确落点和接触阴影，杜绝悬浮残疾感

### 输出规范
- 透明背景
- 4~5px 均匀圆润白边
- 轻微柔和投影
- 300 DPI，适合印刷刀模
